# Move+ Documentation

This repository is the **canonical public documentation source** for Move+ products.

## Documentation sections

Public documentation is organized into two separate application sections:

1. **Move+** — `docs/public/applications/move-plus/`
2. **Move+ Marketplace** — `docs/public/applications/move-plus-marketplace/`

These sections are documented independently and must not be conflated.

## Content policy

- Final documentation is **manually authored and approved** before publication.
- Placeholder pages in this repository are scaffolds only; they are not finished public content.
- Implementation repositories (including application source) remain **private** and are not copied into this repository.

## Assets

Product assets intended for public documentation may be placed under:

- `assets/move-plus/`
- `assets/move-plus-marketplace/`

See `NOTICE.md` for proprietary branding and materials notice.
